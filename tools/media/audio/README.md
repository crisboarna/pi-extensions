# Audio for the narrated videos

`first-light-particles.mp3` is the music bed under the narrated hero videos (`tools/media/narration.mjs`). It plays quietly, ducked while the voice speaks, and loops with a crossfade when a video is longer than the track.

| Field | Value |
|---|---|
| Title | First Light Particles |
| Author | Yoiyami |
| Source | <https://opengameart.org/content/first-light-particles-%E2%80%93-cc0-atmospheric-pianoambient-track> |
| Licence | CC0 1.0 (public domain dedication): no attribution or permission needed |
| File | the source page's `first_light_particles_1.mp3`, unchanged; 2:12 |
| Retrieved | 2026-10-26 |
| SHA-256 | `b5651fd7847c6acef29255507d620b01a2213d687330a0011f38affecc75709f` |

To replace it, pick a track whose licence needs no attribution (CC0 or public domain), record the same fields here, and keep the file name or update `MUSIC` in `tools/media/narration.mjs`.
