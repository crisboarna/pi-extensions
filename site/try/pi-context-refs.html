Try pi-context-refs live

Real pi and pi-context-refs run here, in your browser, in a WebContainer, in a small project (~/projects/shop-api) with three saved refs: api (a file), terse (a snippet) and notes (a path). The expansion is the real one. The model is a stand-in that answers with the text pi sent it, so you see what a real model would receive. The git command is also a stand-in with one canned change in src/retry.ts, because git does not run in a browser. Nothing leaves the page.
