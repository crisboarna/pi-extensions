Try pi-switchboard: the rule playground

Set the classifier's answers by hand and see which rule fires, whether its confidence passes the gate, and which tier the request lands on. This page runs pi-switchboard's own rules and tier decision on the config below, as /tier try work=… depth=… risky=… does. Nothing leaves the page.

    Which member of the tier runs depends on the tier's strategy and on live account health, which this page does not have.
