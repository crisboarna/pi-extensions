Try pi-context-refs: the ref playground

Write a message with refs in it, like [ref:api] or #diff, and see what pi-context-refs does with it: the picker rows, the refs it resolves, the text the model receives, the line the transcript keeps, and the /ref list output. This page runs pi-context-refs' own code on the library, files and message below. Nothing leaves the page.

Simulated: git does not run in the page, so #diff, #status and #log print the canned output in the "command output" box. URL refs are not supported here.
